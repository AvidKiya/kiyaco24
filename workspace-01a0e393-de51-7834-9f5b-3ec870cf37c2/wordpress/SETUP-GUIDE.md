# 🚀 راهنمای کامل راه‌اندازی فروشگاه «کیا» روی هاست ایران (ماهانس/سی‌پنل)

> هدف: سایت رو **ساده، ارزان و بدون دردسر** بالا بیاریم؛ مدیریت محتوا کاملاً از پنل باشه؛
> ۱۰۰ نفر همزمان سفارش بدن سایت نخوابه؛ پرداخت با **زرین‌پال** + **کارت‌به‌کارت با رسید** + **کیف پول**.

---

## چرا وردپرس + ووکامرس؟ (تصمیم فنی)

| معیار | وردپرس + ووکامرس | نسخهٔ Next.js فعلی |
|---|---|---|
| اجرا روی هاست ارزان سی‌پنل (ماهانس) | ✅ استاندارد (PHP + MySQL) | ❌ نیاز به هاست Node.js گران‌تر |
| مدیریت محتوا بدون کد | ✅ کامل | ⚠️ نیاز به توسعه |
| افزونهٔ درگاه زرین‌پال رایگان | ✅ رسمی و رایگان | ❌ باید کد نوشته شود |
| کارت‌به‌کارت با رسید + تأیید پنل | ✅ افزونهٔ آماده | ❌ باید ساخته شود |
| کیف پول مشتری | ✅ TeraWallet رایگان | ❌ باید ساخته شود |
| پیامک (کاوه‌نگار/SMS.ir) | ✅ افزونهٔ آماده | ❌ باید کد نوشته شود |
| ورود با تلگرام | ✅ (پلاگین `kiya-core` که زدم) | ❌ باید ساخته شود |
| تحمل ۱۰۰ کاربر همزمان | ✅ با کش LiteSpeed | ✅ |
| هزینهٔ ماهانه | پایین (هاست اشتراکی) | بالا (سرور Node + پستگرس) |

**نتیجه:** برای شروع فروش واقعی با کمترین هزینه → **WordPress**. کد Next.js که ساختیم به‌عنوان نسخهٔ پیشرفتهٔ آیندی (وقتی بودجهٔ سرور داشتی) نگه داشته می‌شه.

## گام ۰ — چک‌لیست خرید/آماده‌سازی هاست

- [ ] پلن هاست **لینوکس + cPanel** (ماهانس: پلن‌های میزبانی وب معمول) — حداقل **۵–۱۰ گیگابایت فضای SSD**
- [ ] **LiteSpeed** روی سرور (ماهانس بیشتر پلان‌ها LiteSpeed دارند — مهم‌ترین نکتهٔ کارایی)
- [ ] **SSL رایگان** (Let's Encrypt) فعال باشد
- [ ] PHP ≥ ۸.۱ و MySQL ≥ ۵.۷
- [ ] دامنهٔ `.ir` یا `.com` ثبت و به هاست متصل
- [ ] بکاپ خودکار هاست فعال

## گام ۱ — نصب وردپرس (۵ دقیقه)

1. وارد cPanel شو → **WordPress Manager by Softaculous** (یا «نصب وردپرس»)
2. دامنه رو انتخاب کن → تنظیمات:
   - نام سایت: `کیا اکسسوری`
   - یوزر ادمین: **یک نام غیرمعمول** (مثل `kiya_admin_92`)، هرگز `admin` نباش
   - رمز: **حداقل ۱۶ کاراکتر تصادفی** (از Password Manager مرورگرت استفاده کن)
   - ایمیل: ایمیل واقعی خودت
3. نصب رو تمام کن و وارد `/wp-admin` شو

> 💡 اگر Softaculous نیست: از بخش «MySQL Databases» یه دیتابیس + یوزر بساز، وردپرس رو از wordpress.org دانلود و در `public_html` آپلود کن.

## گام ۲ — تنظیمات پایهٔ فارسی و راست‌چپ

1. **Settings → General**: زبان سایت `فارسی`، زمان `Tehran`
2. **Settings → Permalinks**: `Post name` (`/%postname%/`) — برای سئو
3. **Settings → Reading**: «بایدنمودن به موتورهای جستجو» را **بدون تیک** بگذار (بعد از آماده‌شدن نهایی سایت، تیک بزن)
4. **Users → Profile**: زبان پنل `فارسی`

## گام ۲.۵ — لوگو، فونت و رنگ برند (پیش‌نیاز ظاهر سایت)

فایل‌ها در پوشهٔ `brand/` و `fonts/` این بسته آماده‌اند:

| فایل | کاربرد | مسیر روی هاست |
|---|---|---|
| `brand/logo-light.png` | لوگو با حروف تیره (روی پس‌زمینهٔ روشن) | لوگوی هدر |
| `brand/logo-dark.png` | لوگو با حروف سفید (روی پس‌زمینهٔ تیره) | لوگوی فوتر/حالت تاریک |
| `brand/favicon-32x32.png` | آیکون تب مرورگر | `wp-content/` یا آپلود در تنظیمات قالب |
| `brand/icon-192.png` / `icon-512.png` | آیکون PWA | برای نصب اپ روی موبایل |
| `fonts/Vazirmatn.woff2` | فونت فارسی کل سایت | `wp-content/fonts/` |

**رنگ طلایی برند: `#D19B44`** — در سفارشی‌سازی قالب (Blocksy) به‌عنوان رنگ اصلی/لینک‌ها بگذار تا همه‌جا یکدست باشد.

**فونت:**
- Blocksy → **نمایش > سفارشی‌سازی > Typography** → فونت اصلی `Vazirmatn`
- اگر قالب فونت سفارشی قبول نکرد: پوشهٔ `fonts/` را در `wp-content/` کپی کن و از افزونهٔ «Custom Fonts» یا کد زیر در `Appearance > Customize > Additional CSS` استفاده کن:

```css
@font-face{font-family:Vazirmatn;src:url('/wp-content/fonts/Vazirmatn.woff2') format('woff2');font-weight:100 900;font-display:swap}
body,h1,h2,h3,h4,h5,h6,.site-title{font-family:Vazirmatn,Tahoma,sans-serif}
```

## گام ۴ — تنظیم ووکامرس

1. **WooCommerce → تنظیمات → عمومی**: واحد پول `ریال` یا `تومان` (یکی رو انتخاب کن و ثابت نگه دار — توصیه: **تومان**)، آدرس مغازه، فروش دیجیتال: خاموش
2. **مالیات**: خاموش (تا اطلاع ثانیه)
3. **ارسال**: منطقهٔ `سراسر ایران` + هزینهٔ ثابت `۶۵٬۰۰۰` + **ارسال رایگان بالای `۱٬۵۰۰٬۰۰۰` تومان**
4. **پرداخت**: زرین‌پال (فعال) + کارت‌به‌کارت (فعال) + کیف پول (فعال)
5. **حساب کاربری**: «بازدیدکنندگان بتوانند سفارش دهند» فعال (خرید بدون ثبت‌نام)
6. **محصولات → دسته‌بندی‌ها»: بساز:
   - کمربند (زنانه، پهن، باریک، مجلسی، چرمی، زنجیری، پارچه‌ای، فانتزی)
   - اکسسوری (گردنبند، دستبند، انگشتر، گوشواره، پابند، گیره مو، اکسسوری کیف)
   - بدلیجات (مینیمال، مجلسی، روزمره، استیل، ست‌ها)

## گام ۵ — افزودن محصولات (مهم!)

برای هر محصول:
1. **محصول جدید** → نام، توضیح فروشندگی، دسته
2. **دادهٔ محصول → تنوع‌ها**:
   - کمربند: ویژگی `سایز` با مقادیر `۹۰, ۹۵, ۱۰۰, ۱۰۵, ۱۱۰, ۱۱۵, ۱۲۰` + ویژگی `رنگ` (مشکی، قهوه‌ای، کرم)
   - گردنبند/دستبند: `سایز` طول/دور + `رنگ`
   - انگشتر: `سایز` ۸ تا ۱۲
   - هر تنوع **قیمت و موجودی مستقل** دارد ✅
3. **تصویر شاخص** + **گالری** (۳–۵ عکس مربی با نور یکنواخت)
4. **توضیحات کوتاه** + **برچسب‌ها** (جدید/پرفروش)
5. **سئو** (با Yoast یا Rank Math رایگان): عنوان + توضیح متا

> 📸 عکسرا فعلاً placeholder هستند — هر وقت عکس واقعی مغازه رو داری، از **رسانه → افزودن** جایگزین کن. نیازی به کد نیست.

## گام ۶ — اتصال درگاه زرین‌پال

1. در پنل [zarinpal.com](https://zarinpal.com) ثبت‌نام کن → **درخواست درگاه** (نیاز به کد ملی/شبا/پروندهٔ کسب‌وکار)
2. بعد از تأیید، **مرچنت کد** (Merchant ID) رو بگیر
3. وردپرس → **ووکامرس → تنظیمات → پرداخت → زرین‌پال**: مرچنت کد رو وارد کن → فعال کن
4. تست با یه سفارش واقعی کوچک (بعداً مرجوع کن)

> ⚠️ زرین‌پال به HTTPS (SSL) نیاز داره. حتماً SSL فعال باشه.

## گام ۷ — کارت‌به‌کارت با رسید و تأیید از پنل (بدون نیاز به افزونهٔ اضافه)

> ✅ این بخش با **درگاه اختصاصی داخل پلاگین `kiya-core`** انجام می‌شود — هیچ افزونهٔ جانبی لازم نیست.

1. **ووکامرس → تنظیمات → پرداخت → «کارت به کارت (کیا)» → فعال کن**
2. تنظیماتش:
   - **عنوان**: `کارت به کارت`
   - **شماره کارت‌ها** (هر کارت یک خط): `۶۱۰۴-۳۳۷۸-۰۰۰۰-۰۰۰۰ | بانک ملت | نام صاحب حساب`
   - **نام صاحب حساب**: نام خودت
   - **آپلود رسید اجباری**: تیک بخورد (پیشنهادی)
   - **وضعیت سفارش بعد از ثبت**: `در انتظار بررسی`
3. مشتری در تسویه، کارت‌ها را می‌بیند، **رسید را آپلود** می‌کند (+ شماره پیگیری/۴ رقم آخر اختیاری)
4. سفارش وارد وضعیت `در انتظار بررسی` می‌شود
5. **تو پنل → ووکامرس → سفارش‌ها → سفارش را باز کن** → جعبهٔ «🧾 رسید پرداخت کارت به کارت» → تصویر رسید را ببین → دکمهٔ **✅ تأیید پرداخت و ثبت دریافت وجه** → وضعیت خودکار `در حال آماده‌سازی` + تاریخ پرداخت ثبت می‌شود
6. مشتری خودکار پیامک/ایمیل «پرداخت تأیید شد» می‌گیرد

> 🔒 امنیت: فایل‌های رسید در پوشهٔ `wp-content/uploads/kiya-receipts/` با نام تصادفی ذخیره می‌شوند و اجرای کد در آن پوشه با `.htaccess` بسته است.

> 📲 **از تلگرام هم می‌توانی تأیید کنی** — پلاگین `kiya-core` برای هر سفارش پیام با دکمهٔ «✅ تأیید پرداخت / ❌ رد / 📦 آماده‌سازی / 🚚 ارسال شد» می‌فرستد و **تصویر رسید را هم به‌صورت عکس پیوست می‌کند**. فقط یک دکمه بزن، وضعیت در پنل عوض می‌شود.

## گام ۸ — کیف پول مشتری (TeraWallet)

1. نصب و فعال‌سازی → **کیف پول → تنظیمات**:
   - حداقل شارژ: `۱۰۰٬۰۰۰` تومان، حداکثر: `۲۰٬۰۰۰٬۰۰۰`
   - درگاه شارژ: **زرین‌پال** (مشتری با زرین‌پال کیف پولش رو شارژ می‌کنه)
   - بازگشت وجه از کیف پول: فعال
2. مشتری از **حساب کاربری → کیف پول** شارژ می‌کنه و تو خرید استفاده می‌کنه

## گام ۹ — پیامک (کاوه‌نگار یا SMS.ir)

1. تو پنل پیامک (مثلاً کاوه‌نگار) ثبت‌نام کن → **API Key** بگیر (اعتبار نمونه‌ای رایگان می‌ده)
2. افزونهٔ پیامک ووکامرس فارسی → API Key رو وارد کن
3. پیامک‌های خودکار رو فعال کن:
   - ثبت سفارش (به مشتری + به خودت)
   - تغییر وضعیت (پرداخت شد / ارسال شد)
   - خوش‌آمدگویی به عضو جدید
4. قالب پیامک: `مشتری گرامی، سفارش شما با کد {order_id} ثبت شد. کیا`

> 💡 ورود با پیامک (OTP) هم با همین پنل + افزونهٔ ورود با شماره موبایل ممکنه (توصیه: «ورود با پیامک وردپرس»). اگر خواستی، کد اختصاصی برات می‌نویسم.

## گام ۱۰ — ورود با اکانت تلگرام (پلاگین kiya-core)

1. پوشهٔ `kiya-core` رو توی `wp-content/plugins/` آپلود و فعال کن
2. تو [@BotFather](https://t.me/BotFather):
   - `/newbot` → توکن ربات رو بگیر (مثل `8123456789:AAH...`)
   - `/setdomain` → دامنهٔ سایتت رو ثبت کن (مثل `kiya.shop`) — **برای ویجت ورود الزامیست**
3. وردپرس → **تنظیمات → کیا تلگرام**:
   - توکن ربات
   - یوزرنیم ربات (بدون @)
   - آیدی عددی چت مدیر (از [@userinfobot](https://t.me/userinfobot) بگیر) — اعلان سفارش‌ها میره اینجا
4. حالا تو صفحهٔ ورود/ثبت‌نام دکمهٔ **«ورود با تلگرام»** هست ✅

## گام ۱۱ — کارایی: تحمل ۱۰۰ کاربر همزمان ⚡

**مهم‌ترین بخش برای اینکه سایت نخوابه:**

1. **LiteSpeed Cache** → تنظیمات:
   - Cache: ON | کش مرورگر: ON
   - **استثناها (بسیار مهم):** `/cart`, `/checkout`, `/my-account/*`, `/wp-admin/*` رو از کش **خارج** کن (این‌ها پیش‌فرض استثنا هستند، چک کن)
   - بهینه‌سازی CSS/JS: ON | بارگذاری تنبل تصاویر: ON
2. **تصاویر**: قبل از آپلود، عکس‌ها رو با TinyPNG فشرده کن + Smush
3. **Object Cache**: اگر هاست Redis داشت فعال کن (اگر نبود، LiteSpeed Object Cache کافیه)
4. **افزونه‌ها**: فقط لیست گام ۳. هر افزونهٔ اضافی سرعت رو می‌کشه
5. **پایگاه داده**: هفته‌ای یک بار با افزونهٔ WP-Optimize تمیزسازی کن
6. **CDN (اختیاری)**: آروان کلود برای سرعت داخل ایران

> 📊 **چرا ۱۰۰ نفر مشکل نیست؟** وقتی LiteSpeed Cache فعاله، صفحه‌های محصول از کش سرو می‌شن و سرور فقط برای تسویه‌حساب کار می‌کنه. زرین‌پال هم ترافیک پرداخت رو خودش مدیریت می‌کنه. تنها بخش حساس: **صفحهٔ تسویه** — که به‌خاطر исключенияهای بالا کش نمی‌شه و سبکه.

## گام ۱۲ — امنیت 🔒

1. SSL (HTTPS) اجباری — `Settings → General` هر دو نشانی رو با `https` کن
2. Wordfence → فایروال + اسکن هفتگی
3. **محدود کردن تلاش ورود** (Limit Login Attempts)
4. تغییر آدرس صفحهٔ ورود (WPS Hide Login) — `/wp-admin` رو مخفی کن
5. رمز ادمین قوی + **تأیید دو مرحله‌ای** (Google Authenticator)
6. UpdraftPlus → بکاپ روزانه به Google Drive/Dropbox
7. هیچ‌وقت افزونهٔ کرک‌شده نصب نکن

| سایت کند شد | LiteSpeed Cache + حذف افزونهٔ اضافی + بهینه‌سازی عکس |
