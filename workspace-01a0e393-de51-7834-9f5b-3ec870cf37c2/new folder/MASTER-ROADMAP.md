## 🆕 تصمیم استراتژیك (۱۴۰۵/۰۷/۰۵) — بستهٔ وردپرس روی هاست ایران = مسیر اصلی تحویل

**تصمیم مالک:** بودجه محدود است و سایت باید روی **هاست اشتراکی ارزان ایرانی (ماهان‌هاست/سی‌پنل)** اجرا شود، مدیریت محتوا ساده بماند، و ۱۰۰ کاربر همزمان بتوانند سفارش/پرداخت کنند.

| سوال | تصمیم |
|---|---|
| چه چیزی تحویل داده می‌شود؟ | **بستهٔ کامل وردپرس + ووکامرس** در `/home/user/wordpress/` — آمادهٔ آپلود روی هاست اشتراکی |
| Next.js چه می‌شود؟ | **مسیر ارتقای آینده** (self-hosted). همچنان نگهداری و کامیت می‌شود، اما اولویت اول نیست. |
| پرداخت | **درگاه زرین‌پال** (افزونهٔ رسمی `zarinpal-woocommerce-payment-gateway`) + **کارت‌به‌کارت با آپلود رسید و تأیید از پنل** (درگاه اختصاصی داخل `kiya-core`) |
| کیف پول مشتری | **TeraWallet** (`woo-wallet`) |
| پیامک | **کاوه‌نگار / SMS.ir** از طریق `persian-woocommerce-sms` |
| تلگرام | **ورود/ثبت‌نام با تلگرام** + **اعلان سفارش به ربات** + **تأیید/رد رسید با دکمهٔ inline** → پلاگین اختصاصی `kiya-core` |
| عملکرد ۱۰۰ کاربر همزمان | LiteSpeed Cache با استثنای cart/checkout/my-account + Redis Object Cache (اگر هاست داشت) + تنظیمات دقیق در `SETUP-GUIDE.md` گام ۱۱ |
| امنیت | Wordfence + SSL + محدودیت تلاش ورود + بکاپ خودکار + فایل‌های رسید در پوشهٔ محافظت‌شده |
| زبان/سمت | فارسی + راست‌چپ کامل، واحد ریال/تومان، تاریخ شمسی |
| فونت | Vazirmatn (فایل `fonts/Vazirmatn.woff2` در بسته) |

**فایل‌های بستهٔ تحویل وردپرس:**

| مسیر | محتوا |
|---|---|
| `wordpress/SETUP-GUIDE.md` | راهنمای گام‌به‌گام فارسی برای ماهان‌هاست/سی‌پنل (نصب → فارسی‌سازی → ووکامرس → زرین‌پال → کارت‌به‌کارت → کیف پول → پیامک → تلگرام → کارایی → امنیت → چک‌لیست) |
| `wordpress/kiya-core/kiya-core.php` | ورود تلگرام (اعتبارسنجی HMAC-SHA256) + اعلان سفارش با دکمه‌های inline + وب‌هوک + صفحهٔ تنظیمات |
| `wordpress/kiya-core/kiya-card-to-card.php` | درگاه کارت‌به‌کارت: آپلود رسید (JPG/PNG/PDF تا ۵MB) + ذخیرهٔ امن + تأیید از پنل + ارسال تصویر به ربات |
| `wordpress/plugins-list.md` | لیست افزونه‌ها با اسلاگ رسمی WP.org (تأییدشده با API) + نسخه‌ها |
| `wordpress/brand/` | لوگوی واقعی تم روشن/تاریک + favicon + آیکون PWA |
| `wordpress/fonts/` | فونت Vazirmatn.woff2 |

**قوانین برند که در هر دو مسیر رعایت می‌شود:** رنگ طلایی `#D19B44`، لوگوی واقعی مالک (به‌جای placeholder)، گوشهٔ معکوس **کاربردی و کم‌مصرف** (نه تزئینی و اغراق‌آمیز)، فضای منفی باید عنصر کاربردی داشته باشد (CTA/برج/بیلد).

## بخش ۲ — نقشه فازبندی کامل (۱۷ فاز + فاز صفر)

> قاعدهٔ طلایی هر فاز: **ساخت → اجرا → بررسی → پیدا کردن مشکل → رفع → بهبود → تست → فاز بعد**
> هیچ‌وقت با مشکل شناخته‌شده به فاز بعد نرویم.

### 🔴 فاز ۰ — رفع بلاکرها و پایه (قبل از هر چیز)
**هدف:** سایت با تصاویر واقعی بالا بیاید و آمادهٔ توسعه باشد.
- اضافه‌کردن لوگو (نسخهٔ dark/light/favicon/PWA icon) → `public/`
- تولید/اضافه‌کردن تصاویر هیرو و محصولات → `public/images/`
- بررسی `next.config.ts` برای بهینه‌سازی تصویر (sharp از قبل هست ✅)
- تنظیم `.env` واقعی (DATABASE_URL, ADMIN_SETUP_KEY, SITE_URL)
- `npx drizzle-kit push` و بررسی سلامت
- **QA:** بیلد production بدون خطا، بررسی بصری دسکتاپ/موبایل، Lighthouse اولیه

### 🎨 فاز ۱ — دیزاین‌سیستم v2 + زبان بصری «گوشهٔ معکوس کاربردی»
**هدف:** یک زبان بصری متمایز، تمیز و کنترل‌شده.
- Design Tokens کامل در `globals.css`: رنگ (primary/background/surface/text/muted/border/success/warning/error)، تایپوگرافی، فاصله، شعاع، سایه
- سیستم **Inverted Corner** به‌صورت utility/کامپوننت قابل‌استفادهٔ مجدد: `inverted-top-left/right`, `bottom-left/right` با پارامتر size/radius/depth/position/responsive
- **قانون طلایی:** فقط در هیرو، بنرهای ویژه، کارت‌های ادیتوریال، کالکشن‌ها و CTAهای خاص — نه همهٔ کارت‌ها
- **استفادهٔ فضای تو‌رفته:** هر گوشهٔ تو‌رفته باید یک عنصر کارکردی بگیرد (دکمهٔ CTA، فلش، بج تخفیف، میان‌بر دسته، لیبل ادیتوریال) — اگر نه، تمیز بماند
- Dark/Light/System (موجود → پالیش + کنتراست)
- **QA:** بررسی زیبایی‌شناختی، کنتراست WCAG AA، عدم شلوغی، موبایل

### 🏠 فاز ۲ — ویترین v2 (Homepage ۲.۰)
- Hero Campaign مدیریت‌پذیر (تصویر/ویدیو/عنوان/CTA/تاریخ شروع-پایین) — چند اسلاید

- **SHOP THE LOOK**: «THE BLACK LOOK» → افزودن کل ست به سبد
- Featured Collection + مزایا + Social Proof + خبرنامه
- ریتم بصری متناوب (گرید/ادیتوریال/اسکرول افقی/نامتقارن)
- **QA:** سرعت LCP، عدم شبیه‌سازی همهٔ سکشن‌ها، موبایل

### 🛍️ فاز ۳ — فروشگاه v2 (Shop)

- **سیستم معرف (Referral):** لینک اختصاصی، رصد کلیک/ثبت‌نام/خرید، پاداش قابل تنظیم
- **QA:** چرخهٔ امتیازدهی و ارتقای سطح

### 🔔 فاز ۱۰ — اعلان‌ها و مارکتینگ اتومیشن
- اعلان‌ها: وضعیت سفارش، پرداخت، ارسال، موجود شدن، کاهش قیمت، کالکشن جدید، به‌روزرسانی همکاری
- کانال‌ها: SMS (کاوه‌نگار/SMS.ir)، Email، Web Notification، Push (PWA)
- اتوماسیون: سبد رهاشده، خوش‌آمد، اولین خرید، بازگشت مشتری، تولد، کاهش قیمت، کالکشن جدید
- **QA:** ارسال واقعی تستی هر کانال

### 🤖 فاز ۱۱ — لایهٔ هوش مصنوعی
- **مشاور استایل چت‌بات** (سایت + ربات): کوئیز مناسبت/بودجه/سلیقه → ۲-۳ ست کامل
- **جستجوی زبان طبیعی:** «یه کمربند برای استایل مشکی مجلسی می‌خوام» → محصولات مرتبط
- **پیشنهاد سایز هوشمند** (قد/وزن/سایز معمول + جدول اندازه)
- **پیشنهاد هوشمند محصول** (مشابه/مکمل/ cross-sell / upsell / «مخصوص شما»)
- **تحلیل ترند** (فروش + جستجو + نظرسنجی کانال → ترند رشد/افت + پیشنهاد خرید)
- **تولید کپشن خودکار** (اینستاگرام/کانال/صفحه محصول)
- معماری: لایهٔ AI مجزا با integration points (بدون hardcode) — قابل اتصال به سرویس ایرانی/واسط/مدل متن‌باز
- **QA:** دقت پاسخ‌ها، عدم توهم محصول، هزینهٔ توکن

### 📱 فاز ۱۲ — ربات تلگرام کامل
- کانال: انتشار خودکار محصول/کالکشن/فلش‌سل + پست ادیتوریال
- ربات: `/start`, مرور دسته‌ها، جستجو، سبد، ثبت سفارش، `/orders` پیگیری، `/size` مشاوره سایز، `/stylist` چت AI، `/support` پشتیبانی
- ادمین: `/broadcast`, `/notify`, `/reply_<id>`, `/stats`
- **QA:** چرخهٔ کامل خرید از تلگرام، اتصال به همان دیتابیس سفارش

### ⚙️ فاز ۱۳ — پنل مدیریت v2 (CMS کامل)
- **Homepage Builder:** افزودن/حذف/ترتیب/فعال‌سازی سکشن‌ها بدون کد (عنوان، تصویر، محصولات، CTA، پس‌زمینه، نوع چیدمان)
- **بنر چندگانه:** تصویر دسکتاپ/موبایل، متن، CTA، لینک، زمان شروع/پایان، اولویت، کمپین
- **مدیریت منو:** هدر، فوتر، مگامنو، منوی موبایل
- مدیریت محتوا: مقالات، ادیشن‌های Fashion Daily، ترندها، نویسندگان، تگ‌ها، انتشار زمان‌بندی‌شده
- مدیریت B2B: بررسی درخواست‌ها، تأیید/رد/تعلیق، سطح قیمت، حداقل سفارش، قیمت همکار
- مدیریت نظرات: تأیید/رد
- **QA:** همهٔ عملیات از پنل بدون دست‌زدن به کد

### 💳 فاز ۱۴ — پرداخت، پیامک و مرجوعی
- اتصال درگاه ایرانی (زرین‌پال/آیدی‌پی) با تأیید تراکنش سمت سرور + رسید
- ورود مشتری با پیامک تراکنشی
- گردش مرجوعی: درخواست→تأیید/رد→بازپرداخت
- روش‌های ارسال: هزینه/آستانهٔ رایگان/شهری/وزنی
- **QA:** چرخهٔ پرداخت موفق/ناموفق، مرجوعی

### 🔍 فاز ۱۵ — SEO، آنالیتیکس و BI
- فیلدهای SEO برای محصول/دسته/کالکشن/مقاله/ترند/راهنما: عنوان، توضیح، اسلاگ، canonical، OG image
- Schema Markup: Product, Article, Breadcrumb, Organization, FAQ, Review
- sitemap.xml + robots.ts (موجود → گسترش)
- آنالیتیکس: بازدید محصول، افزودن به سبد، checkout، خرید، جستجو، علاقه‌مندی، بازدید مقاله، درخواست عمده
- BI: پرفروش/کم‌فروش، نرخ تبدیل، سبد رهاشده، CLV، تکرار خرید، AOV، درآمد retail vs wholesale
- **QA:** Rich Results Test، Core Web Vitals

### 📲 فاز ۱۶ — PWA v2، کارایی، دسترس‌پذیری، QA نهایی
- Push Notification واقعی
- کارایی: Core Web Vitals، بهینه‌سازی تصویر (WebP/AVIF)، Lazy Loading، Code Splitting، کش
- دسترس‌پذیری: کیبورد، ARIA، فوکوس، کنتراست، اسکرین‌ریدر
- Empty/Loading/Error States کامل
