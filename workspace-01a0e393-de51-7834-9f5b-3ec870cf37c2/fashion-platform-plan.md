> مستند راهبردی — نسخه ۱.۰ | تهیه‌شده در ۲۰۲۶-۰۹-۲۶

## ۱. جواب کوتاه: چه مد سایتی باید داشته باشی؟

### ✅ پیشنهاد: **موبایل‌فرست PWA فروشگاهی مد (Fashion E‑Commerce) با طراحی ادیتوریال**

یعنی یه وب‌اپلیکیشن که:

| ویژگی | چرا برای تو ضروریه |
|---|---|
| **موبایل‌فرست (Mobile‑First)** | ۸۰–۹۰٪ مخاطبت (خانم‌ها) از اینستاگرام و تلگرام با موبایل میان. سایت باید روی موبایل مثل یه **اپ** کار کنه. |
| **PWA (قابل نصب روی homescreen)** | بدون needing to app store، کاربر آیکونت رو می‌زنه صفحه گوشی‌اش، آفلاین هم کار می‌کنه، نوتیف پوش داری. |
| **بصری‌محور / ادیتوریال** | پوشاک = فروش احساس و تصویر. سایت باید مثل یه **مجله مد** باشه (لوک‌بوک، کمپین، ست‌های آماده)، نه فقط لیست قیمت. |
| **RTL کامل + فارسی** | تایپوگرافی فارسی درست (فونت وزیرمتن/ایران‌سنس)، اعداد فارسی، چیدمان راست‌به‌چپ. |
| **یکپارچه با تلگرام** | کانال + ربات = موتور ورود ترافیک، فروش و پشتیبانی. |
| **هوش مصنوعی به‌عنوان «فروشنده شخصی»** | مشاور استایل AI = تفاوت‌ساز اصلی‌ات مقابل رقبا (بخش ۴). |

### ❌ چه مدلایی **نمی‌خوای**:
- سایت کلاسیک دسکتاپ‌محور شبیه فروشگاه‌های قدیمی
- فقط فروشگاه اینستاگرامی (بسته، غیرقابل جستجو، بدون اعتمادسازی)
- اپ native (گران، کند در آپدیت، نیاز به استورها)

## ۲. نقشه سایت (Site Map)

```
ژیوار
├── 🏠 خانه (Hero + لوک‌بوک + ترندها + جدیدترین‌ها)
├── 🛍️ فروشگاه
│   ├── پوشاک (پیراهن، شلوار، مانتو، ست، بافت، کاپشن...)
│   ├── اکسسوری (گوشواره، گردنبند، ساعت، کیف، شال/روسری...)
│   ├── لباس زیر (ست، سوتین، پیژامه...)
│   ├── ست‌های آماده (AI + استایلیست، «یکجا بخر»)
│   └── تخفیف‌ها / فروش ویژه
├── 🤖 مشاور هوشمند استایل (کوپون کوئیز + چت AI)
├── 🔍 جستجو (متنی + تصویری + فیلتر پیشرفته: سایز، رنگ، قیمت، مناسبت)
├── 📄 صفحه محصول (گالری، ویدیو، سایزگاید، نظرات، «این ست رو با این بپوش»)
├── 🛒 سبد خرید → تکمیل سفارش (درگاه پرداخت ایرانی)
├── 👤 حساب کاربری (سفارش‌ها، پیگیری، علاقه‌مندی‌ها، سایز و اندازه‌های من)
├── 📦 پیگیری سفارش
├── 📰 وبلاگ / استایل‌گاید (SEO + اعتمادسازی)
├── 💬 ارتباط با ما + پشتیبانی آنلاین
└── 📱 لندینگ اپ + دعوت به کانال و ربات تلگرام
```

## ۳. موتور هوش مصنوعی (قلب تفاوت‌ساز)

| قابلیت | توضیح | اولویت |
|---|---|---|
| **مشاور استایل چت‌بات** | کاربر می‌گه «برای یه قرار مهم شب، ست شیک و راحت می‌خوام تا ۲ میلیون» → AI ۳ ست کامل با لینک خرید پیشنهاد می‌ده | ⭐ فاز ۳ |
| **کوییز استایل + پرسونالایزیشن** | ۵ سوال (شکل بدن، رنگ، بودجه، سلیقه، مناسبت) → پروفایل استایل + صفحه اصلی شخصی‌سازی‌شده | ⭐ فاز ۳ |
| **پیشنهاد سایز هوشمند** | با قد/وزن/اندازه‌های ذخیره‌شده کاربر، «سایز پیشنهادی: M (۹۵٪ تطابق)» → کاهش مرجوعی | ⭐ فاز ۳ |
| **جستجوی تصویری** | عکس یه لباس رو آپلود کن → محصولات مشابه | فاز ۴ |
| **تحلیل ترند** | AI ترندهای اینستاگرام/پینترست رو رصد می‌کنه → پیشنهاد «ایتم‌های داغ این هفته» برای خرید و محتوا | فاز ۴ |
| **سازنده ست خودکار (Outfit Builder)** | روی هر محصول دکمه «ست کامل رو ببین» → AI اکسسوری و لایه‌های مناسب رو پیشنهاد می‌ده (افزایش سبد خرید) | فاز ۴ |
| **توضیحات و کپشن خودکار** | تولید متن فروشندگی، کپشن اینستاگرام و کپشن کانال تلگرام برای هر محصول | فاز ۳ |
| **چت‌بات پشتیبانی ۲۴/۷** | پاسخ به سوالات متداول، پیگیری سفارش، جایگزین بخشی از پشتیبانی انسانی | فاز ۲ |

> ⚠️ **نکته مهم فنی (ایران):** API‌های OpenAI/Claude برای IP ایران مسدودند. گزینه‌های عملی:
> 1. سرویس‌دهنده‌های ایرانی AI (اگر موجود و پایدار باشند)
> 2. سرور خارج از ایران + واسط API برای ربات/سایت (کانال اختصاصی)
> 3. میزبانی مدل‌های متن‌باز (Llama / Qwen فارسی) روی سرور GPU
> 4. در شروع: سیستم پیشنهاد ساده (Rule‑based + فیلترینگ) و ارتقای بعدی به LLM

## ۴. اکوسیستم تلگرام

### 📣 کانال «ژیوار استایل»
- پست جدیدترین محصولات با عکس و قیمت
- فلش‌سل ۲۴ ساعته (فقط برای اعضای کانال)
- پست‌های استایل روزانه + نظرسنجی («کدوم رنگ؟»)
- پشت صحنه برند (اعتمادسازی)

### 🤖 ربات «ژیوار»
| قابلیت | توضیح |
|---|---|
| `/start` | ثبت‌نام + کوپون خوش‌آمدگویی |
| جستجوی محصول | فوری داخل چت، با دکمه‌های شیشه‌ای (Inline) |
| مشاوره سایز | وارد کردن اندازه‌ها → پیشنهاد سایز |
| سفارش | انتخاب محصول → پرداخت → رسید |
| `/orders` | پیگیری وضعیت سفارش با وضعیت زنده |
| نوتیف | اطلاع‌رسانی موجود شدن محصول ناموجود + تخفیف |
| مشاور AI | چت با مشاور استایل داخل تلگرام |
| پشتیبانی | اتصال به اپراتور انسانی در ساعات کار |

## ۶. فازبندی اجرا (Roadmap)

### 🟢 فاز ۱ — MVP (ماه ۱–۲)
کاتالوگ محصولات، دسته‌بندی، سبد خرید، درگاه پرداخت، پنل ادمین، صفحه محصول با سایزگاید. **هدف: فروش واقعی شروع شود.**

### 🟡 فاز ۲ — تلگرام + اعتمادسازی (ماه ۲–۳)
کانال + ربات (سفارش، پیگیری، پشتیبانی)، نظرات محصولات، وبلاگ با ۱۰ مقاله استایل.

### 🟠 فاز ۳ — هوش مصنوعی (ماه ۳–۴)
مشاور استایل چت‌بات، کوییز پرسونالایز، پیشنهاد سایز، کپشن خودکار.

### 🔵 فاز ۴ — رشد (ماه ۴–۶)
جستجوی تصویری، تحلیل ترند، Outfit Builder، برنامه وفاداری و تخفیف‌های پرسونال.

### 🟣 فاز ۵ — بلوغ (ماه ۶+)
اپلیکیشن native، درگاه عضویت ویژه، Live Shopping در تلگرام/اینستاگرام.

## ۷. کلیدهای موفقیت (تجربیتی)

1. **عکسبرداری حرفه‌ای محصول** — مهم‌ترین عامل فروش پوشاک آنلاین. بودجه‌ات را اول اینجا بگذار.
2. **سایزگاید دقیق + جدول اندازه واقعی** — بیشترین دلیل مرجوعی در پوشاک، سایز اشتباه است.
3. **سیاست مرجوعی آسان** (۷ روز) — حذف ترس خرید آنلاین.
4. **سرعت سایت زیر ۲ ثانیه** روی موبایل — هر ثانیه تأخیر = افت فروش.
5. **تلگرام = پشتیبانی زیر ۱۵ دقیقه** — در ایران، پاسخ سریع = وفاداری.
6. **اینستاگرام = موتور ورود ترافیک** → سایت = جای بستن معامله و اعتمادسازی.
7. **داستان برند** — «ژیوار» فقط فروشگاه نیست، یه استایلیست شخصی است.
