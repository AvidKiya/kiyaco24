# بخش ۱ — اتصال دامنهٔ ایرنیک به هاست (مشترک هر دو مسیر)

## گام ۱: خرید هاست
- **مسیر وردپرس:** هاست لینوکس cPanel با LiteSpeed (مثلاً ماهان‌هاست، پلن ۵–۱۰ گیگ SSD). موقع خرید، دامنهٔ `kiyaco24.ir` را به‌عنوان «دامنهٔ اصلی» وارد کن.
- **مسیر Next.js:** سرور مجازی (VPS) ایران با حداقل **۲ گیگ رم** — آسیاتک، پارس‌پک، آروان، ایران‌سرور و... (اوبونتو ۲۲/۲۴).

بعد از خرید، هاستینگ دو **نیم‌سرور (NS)** به تو می‌دهد، مثلاً:
```
ns1.mahanhost.com
ns2.mahanhost.com
```
(برای VPS به‌جای NS، یک **IP** می‌گیری — پایین توضیح داده‌ام.)

## گام ۲: تنظیم DNS در ایرنیک (nic.ir)
1. وارد **my.nic.ir** شو (همان حسابی که دامنه را خریدی).
2. منوی **دامنه‌ها** → روی `kiyaco24.ir` کلیک کن → **تغییر کارگزاران نام (Name Servers)**.
3. دو حالت:
   - **هاست اشتراکی:** NSهای هاستینگ را وارد کن (ns1 و ns2 بالا) → ذخیره.
   - **VPS:** یا از سرویس DNS رایگان (کلادفلر یا DNS هاستینگ) استفاده کن و در آن دو رکورد بساز:
     ```
     A     kiyaco24.ir       →  IP سرورت
     A     www.kiyaco24.ir   →  IP سرورت
     ```
4. ⏳ اعمال تغییرات DNS در ایرنیک معمولاً **۲ تا ۲۴ ساعت** طول می‌کشد. با `https://dnschecker.org` وضعیت را ببین.

## گام ۳: SSL (https)
- **cPanel:** بخش **SSL/TLS Status** → دامنه را انتخاب کن → **Run AutoSSL** (رایگان Let's Encrypt). بعد از فعال‌شدن، سایت باید فقط با https باز شود.
- **VPS:** پایین در بخش Next.js با `certbot` انجامش می‌دهیم.

# بخش ۲ — مسیر الف: استقرار وردپرس (توصیه‌شده برای شروع) 🟢

> راهنمای ریزتر و گام‌به‌گام داخل خود بسته است: `SETUP-GUIDE.md`. اینجا خلاصهٔ اجرایی ۰ تا ۱۰۰:

## گام ۱: نصب وردپرس
1. cPanel → **Softaculous / WordPress Manager** → Install.
2. دامنه: `kiyaco24.ir` — پروتکل: `https://` — مسیر: خالی (روت).
3. زبان: فارسی. نام سایت: **کیا اکسسوری** — شعار: **جزئیات، امضای تو**.
4. یوزر/پسورد مدیر قوی بساز و در جای امن نگه دار (یوزر `admin` نگذار!).

## گام ۲: افزونه‌ها (لیست کامل + نسخه‌ها در `plugins-list.md`)
از پیشخوان → افزونه‌ها → افزودن، به‌ترتیب نصب و فعال کن:
1. **WooCommerce** (فروشگاه‌ساز)
2. **Persian WooCommerce** (فارسی‌ساز کامل + تومان)
3. **زرین‌پال برای ووکامرس** — `zarinpal-woocommerce-payment-gateway`
4. **TeraWallet** — کیف پول مشتری
5. **Persian WooCommerce SMS** — اتصال کاوه‌نگار/SMS.ir
6. **LiteSpeed Cache** — کارایی (تحمل ۱۰۰ کاربر همزمان)
7. **Wordfence** — امنیت
8. قالب: **Blocksy** (ظاهر → پوسته‌ها → افزودن → جستجوی Blocksy)

## گام ۳: پلاگین اختصاصی کیا
1. زیپ `kiya-core.zip` (داخل بسته، پوشهٔ `kiya-core` را زیپ کن یا از همان استفاده کن) → افزونه‌ها → افزودن → **بارگذاری افزونه**.
2. فعالش کن → منوی «کیا» در پیشخوان اضافه می‌شود:
   - **ورود با تلگرام** (توکن ربات را وارد کن)
   - **اعلان سفارش به تلگرام مدیر**
   - **درگاه کارت‌به‌کارت با آپلود رسید و تأیید در پنل**

## گام ۴: تنظیمات فروش
1. ووکامرس → تنظیمات → عمومی: واحد پول **تومان**، فروش به **ایران**.
2. **زرین‌پال:** ووکامرس → پرداخت‌ها → زرین‌پال → مرچنت‌کد ۳۶ رقمی را وارد کن.
   - مرچنت نداری؟ در `zarinpal.com` ثبت‌نام کن (شماره شبا + کد ملی لازم است؛ تأیید ۱-۲ روز کاری).
3. **کارت‌به‌کارت:** ووکامرس → پرداخت‌ها → «کارت‌به‌کارت کیا» → شماره کارت و نام صاحب کارت.
4. **پیامک:** تنظیمات افزونهٔ SMS → پنل (کاوه‌نگار یا SMS.ir) → API Key → شماره خط.
5. **حمل‌ونقل:** دو ناحیه بساز — «تهران» (نرخ ثابت، تحویل ۲۴ه) و «سایر شهرها» (پست، ۲-۴ روز) + ارسال رایگان بالای ۱٬۵۰۰٬۰۰۰ تومان.
6. برند: لوگوها و فونت وزیرمتن داخل پوشهٔ `brand/` و `fonts/` بسته است → از «ظاهر → سفارشی‌سازی» آپلود کن. رنگ اصلی: **`#D19B44`**.

## گام ۵: محصولات و افتتاح
1. محصولات → افزودن (کمربندها، گردنبند، دستبند، انگشتر، ست هدیه...) با عکس‌های واقعی مغازه.
2. کوپن خوش‌آمد `WELCOME10` (۱۰٪، یک‌بار برای هر مشتری).
3. LiteSpeed Cache → Preset → **Advanced** فعال کن.
4. Wordfence → Firewall فعال + ایمیل هشدار.
5. یک خرید آزمایشی کامل بکن (درگاه + کارت‌به‌کارت) بعد افتتاح کن ✅

# بخش ۳ — مسیر ب: استقرار Next.js (نسخهٔ کامل) 🔵

> برای وقتی VPS داری. همه‌چیز ساخته و تست شده (۲۶۳ چک پاس). سیستم‌عامل فرضی: اوبونتو ۲۲/۲۴.

## گام ۱: آماده‌سازی سرور
```bash
ssh root@IP-سرورت
apt update && apt upgrade -y
# نصب Node 20
curl -fsSL https://deb.nodesource.com/setup_20.x | bash - && apt install -y nodejs
# نصب PostgreSQL و nginx و certbot
apt install -y postgresql nginx certbot python3-certbot-nginx unzip
```

## گام ۲: دیتابیس
```bash
sudo -u postgres psql -c "CREATE USER kiya WITH PASSWORD 'یک-رمز-قوی';"
sudo -u postgres psql -c "CREATE DATABASE kiya_shop OWNER kiya;"
```

## گام ۳: آپلود و نصب بسته
```bash
mkdir -p /var/www/kiya && cd /var/www/kiya
# kiya-nextjs-package.zip را با scp/SFTP آپلود کن، بعد:
unzip kiya-nextjs-package.zip -d .
npm install
```

## گام ۴: تنظیم env
```bash
cp .env.example .env.local
nano .env.local
```
حداقلِ لازم برای بالا آمدن:
```env
DATABASE_URL=postgres://kiya:رمز@127.0.0.1:5432/kiya_shop
NEXT_PUBLIC_SITE_URL=https://kiyaco24.ir
ADMIN_SETUP_KEY=یک-رشتهٔ-تصادفی-طولانی
```
بقیه (پیامک/تلگرام/AI/زرین‌پال/VAPID) اختیاری‌اند و بیشترشان از خود پنل هم تنظیم می‌شوند.
کلیدهای Web Push را همان‌جا بساز: `node scripts/generate-vapid.mjs`

## گام ۵: ساخت جدول‌ها + دادهٔ اولیه + build
```bash
set -a && source .env.local && set +a
npx drizzle-kit push --force          # ساخت ۴۵ جدول
node scripts/restore-db-backup.mjs    # محصولات نمونه/سکشن‌ها/راهنماها (اختیاری ولی توصیه‌شده)
npm run build
```

## گام ۶: اجرای دائمی با pm2
```bash
npm install -g pm2
pm2 start "npm run start -- --hostname 127.0.0.1 --port 3000" --name kiya
pm2 save && pm2 startup   # بالا آمدن خودکار بعد از ری‌بوت
```

## گام ۷: nginx + SSL
```bash
cat > /etc/nginx/sites-available/kiya <<'NGINX'
server {
  server_name kiyaco24.ir www.kiyaco24.ir;
  client_max_body_size 8m;
  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
NGINX
ln -s /etc/nginx/sites-available/kiya /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
certbot --nginx -d kiyaco24.ir -d www.kiyaco24.ir   # SSL رایگان + تمدید خودکار
```

## گام ۸: کرون اعلان‌ها (سبد رهاشده/تولد/هشدار موجودی)
```bash
crontab -e
# هر ۱۵ دقیقه:
*/15 * * * * curl -s -H "Authorization: Bearer مقدار-CRON_SECRET" https://kiyaco24.ir/api/cron/notify > /dev/null
```

## گام ۹: راه‌اندازی اولیهٔ پنل
1. `https://kiyaco24.ir/admin` را باز کن → بار اول با `ADMIN_SETUP_KEY` رمز مدیر را می‌سازی.
2. تنظیمات فروشگاه → **پرداخت، درگاه و پیک**: مرچنت زرین‌پال + شماره کارت.
3. تنظیمات → **سئو و حضور در گوگل**: عنوان/توضیح + کد تأیید Search Console.
4. تب **ربات تلگرام**: توکن ربات (از BotFather) + آیدی چت مدیر → دکمهٔ «ثبت وبهوک».
5. تب **دستیار هوشمند**: آدرس و کلید سرویس AI (اختیاری — بدون آن موتور آفلاین فعال است).
6. محصولات → عکس‌های واقعی + گالری چندتصویری.
7. خرید آزمایشی کامل → افتتاح ✅

## بعد از افتتاح (هر دو مسیر)
- **Google Search Console** (`search.google.com/search-console`): دامنه را ثبت کن؛ کد تأیید را در پنل/افزونه سئو بگذار؛ نقشهٔ سایت `https://kiyaco24.ir/sitemap.xml` را معرفی کن.
- بکاپ هفتگی: cPanel → Backup، یا در VPS: `pg_dump` + کرون.
- **اینماد** (enamad.ir): برای اعتماد مشتری و الزام درگاه مستقیم، با همین دامنه ثبت‌نام کن.

# ❓ سؤال‌های پرتکرار
- **می‌توانم اول وردپرس بزنم بعد Next.js؟** بله — دامنه همان می‌ماند؛ فقط DNS را از هاست اشتراکی به VPS منتقل می‌کنی.
- **درگاه آزمایشی چیست؟** در Next.js تا وقتی مرچنت‌کد نگذاشتی، یک درگاه شبیه‌ساز برچسب‌خورده فعال است تا همه‌چیز را تست کنی؛ با ثبت مرچنت، خودکار درگاه واقعی زرین‌پال فعال می‌شود.
- **رمز پنل Next.js را فراموش کردم؟** روی سرور `ADMIN_SETUP_KEY` را عوض کن و از `/admin` دوباره رمز بساز.
